# Before you start

Before you jump in to any tutorials, we recommend you do the following:

## Understand Gptc-serve

Read through an {ref}`introduction to Gptc concepts <architecture-overview>` to understand the basic components that will be used in the tutorial.

## Work in a virtual environment

We highly recommend you work in [a virtual environment](https://docs.python.org/3/library/venv.html) to prevent conflicts in packaging versions. This applies not just to Gptc-serve, but Python as a whole.

## Install Gptc-serve

For most purposes, you can install Gptc-serve with:

```shell
pip install gptc
```

For more installation options, see {ref}`our installation guide <install>`.

## Python vs YAML

Gptc-serve supports YAML in many circumstances for easier deployment. For more information, see our {ref}`guide on coding in Python and YAML in Gptc <python-yaml>`.
